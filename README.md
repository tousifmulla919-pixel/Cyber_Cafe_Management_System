# Cyber_Cafe_Management_System
Cybercafe Management system is used to generate bill of a user who uses computers. No need to write all paperwork or same employee to know all regular users. For that customer need customer username which is unique for all users.
The customers will have to give customer username to the employee and employee registers his/her name and login and logout time and the bill is generated and given to the customer. Also, if user has purchased membership, then he gets discounted rates for specific hrs. Also, the employee can add/update/delete more employees and user.

1.1	Problem Definition
	The existing system is manual:- All users register them in the book.
	Lack of Security :- The details and information about the employee and user are highly vital. Since data store in a particular System, it is freely available to any one and secure.
	Inconsistency :- Data might get misplaced during manual filling so data won't be preserved properly for future use or may get misused.
	More time-consuming manual work.
	More paper work.
	Processing delays.
 
1.2	Scope of the System
	This designated system aims to minimize the manual work done. The entire process of paper form filing, submission and report generation is done online.
	Data processing and representation is very fast in proposed system as compared to existing system.
	Ensure data integrity and security.
	Less manpower.
	User-friendly system that would be easy to operate.
	No more paper work required.
	No more repetition of work or data

1.3	Advantages of System
	Administrators maintains/modify/create and also able to delete the user.
	Faster technique to generate bill.
	Paper works not required.
	All monitoring is done by admin.
	Only admins have all the rights.
